# RADIUS Manager — مختبر إدارة الشبكات

**الحالة الحالية (2026-11-25):** مختبر غير معتمد للإنتاج؛ راجع [تدقيق المرحلة 01](PHASE01_AUDIT_AR.md) لمعرفة آخر الأدلة والفجوات. لا تُدخل كروت المشتركين الحقيقيين ولا تنقل User Manager حاليا.

## أساس التشغيل (وصف تأسيسي مع تحديث مصادر الصور)

- PostgreSQL في حاوية دون فتح منفذ قاعدة البيانات للخارج.
- خدمة FreeRADIUS 3.x مبنية من مراجعة مصدر مثبتة على Alpine مع تهيئة SQL الرسمية ومنافذ RADIUS مقيدة على loopback افتراضيا.
- ASP.NET Core 10 Web API مع مصادقة مسؤول محلية، وصلاحيات أساسية وقيود عدد الطلبات.
- لوحة ويب عربية RTL محلية، إنشاء/تعديل باقات تجريبية محفوظة في PostgreSQL وإرسال إعداد **السرعة فقط** إلى `radgroupreply`.
- تهيئة أسرار آمنة عشوائية ونسخة `.env` محلية خارج git.
- اختبارات JavaScript و C# واختبارات تكامل قابلة للتشغيل في GitHub Actions.

## متطلبات التشغيل

- Debian/Ubuntu مع Docker Engine وDocker Compose plugin وOpenSSL وBash وأدوات GNU الأساسية. إعداد `.env` لا يحتاج Python على المضيف؛ أدوات الاختبار ومسار التهيئة القديم داخل الحاوية ما زالا يستخدمانه.
- الوصول إلى الإنترنت *وقت بناء صور الحاويات فقط* لتحميل الصور والحزم؛ لا يحتاج المتصفح إلى CDN.
- منافذ 8080/TCP و1812/UDP و1813/UDP محلية على 127.0.0.1 افتراضيا.

## المسار الموصى به للتثبيت الجديد: C# والصورة المخففة (مختبر فقط)

على جهاز التحضير، جهز الصور من المصدر دون تشغيل قاعدة أو حاويات النظام القديم. قد يتطلب بناء الصور الإنترنت؛ تشغيل التثبيت منها لا يتطلبه. استخدم مسارين مطلقين جديدين غير موجودين مسبقا:

```bash
RADIUS_LOCAL_BUILD_ACK=local-lab-only bash scripts/prepare-csharp-local-images.sh "$HOME/radius-images"
(cd "$HOME/radius-images" && sha256sum --check --strict SHA256SUMS)
# احفظ البصمة من جهاز التحضير الموثوق، ولا تعتمد بصمة من حزمة غير موثوقة.
digest=$(sha256sum "$HOME/radius-images/SHA256SUMS" | cut -d ' ' -f1)
# فحص الجهاز والصور المحلية أولا دون إنشاء تثبيت:
RADIUS_LOCAL_INSTALL_ACK=local-lab-only bash scripts/install-csharp-local-lab.sh --check "$HOME/radius-local-lab" --prepared "$HOME/radius-images" "$digest"
# التثبيت بعد نجاح الفحص:
RADIUS_LOCAL_INSTALL_ACK=local-lab-only bash scripts/install-csharp-local-lab.sh "$HOME/radius-local-lab" --prepared "$HOME/radius-images" "$digest"
```

وضع `--check` يتحقق من أدوات المضيف، صلاحية مجلد التثبيت، منصة Docker، سلامة معرفات الصور، تشغيل PostgreSQL بغير root، تشغيل .NET 10 بغير root وملفات API والواجهة، والصورة المخففة؛ يعرض معلومات CPU/RAM والتخزين والمساحة الحرة دون إنشاء تثبيت. لا يثبت تحمّل عدد مشتركين معين أو توافق كل جهاز. اختبارات CI الحالية على Linux amd64؛ قبول ARM64 أو Windows أو Mini PC مادي يحتاج أدلة منفصلة. يجب أن تكون الصور متاحة محليا قبل هذا الفحص.

يمكن أيضا تمرير معرفات DB وAPI وصورة RADIUS المتوافقة الموثوقة إلى سكربت التحضير بعد مسار المخرجات لتجنب إعادة البناء. تستخدم النتيجة نفس محرك C# والمثبت المختبر؛ لا تحتاج .env أو Python على المضيف أو حاوية RADIUS النهائية. صورة التوافق لا تزال وسيطا في بناء الصورة المخففة عبر وصفة التشغيل المعتمدة `radius/Dockerfile.slim`؛ سياق هذه الوصفة مغلق افتراضيا (`**`) باستثناء ملف الوصفة نفسه، ولا ينسخ ملفات من المضيف. لا ينقل هذا الأمر بيانات تثبيت موجود، ولا يعتمد التشغيل للإنتاج. فحص الثغرات والقبول إلزاميان في CI للإصدار المقابل. المسار الأساسي القديم أدناه محفوظ لاختبارات التوافق والاستعادة حتى اعتماد الانتقال الآمن.

## التشغيل القديم (مسار التوافق والاختبارات)

```bash
bash scripts/setup.sh
docker compose config --quiet
docker compose up -d --build
docker compose ps
```

على **الجهاز نفسه** افتح `http://127.0.0.1:8080`.

على جهاز آخر داخل الشبكة افتح نفق SSH (من جهاز العميل):

```bash
ssh -L 8080:127.0.0.1:8080 USER@SERVER_LAN_IP
```

ثم افتح على جهاز العميل `http://127.0.0.1:8080`. استخدم اسم `admin`، واقرأ كلمة المرور من `ADMIN_PASSWORD` في ملف `.env` على الخادم. كلمة المرور لا تُرسل إلى أي موقع خارجي؛ لوحة الإدارة لا تعرضها أو تخزنها في LocalStorage.

## حدود التأسيس التاريخية (راجع التدقيق للحالة الحالية)

1. `quota_bytes` و `validity_days` **مخزنتان كمعلومات فقط وليستا مطبقتين على المصادقة**؛ لا تبيع باقات بهذا الإصدار.
2. لا يوجد إنشاء كروت الإنتاج أو التوزيع أو البيع أو نظام استخدام موحد بعد.
3. لا يوجد تفعيل لتزامن الجلسات أو خصم الرصيد أو فصل الجلسة عند نفاده.
4. ربط MikroTik والشبكات البعيدة عبر VPN سيكون في المرحلة التالية بعد الاختبارات.
5. HTTP Basic مقبول **للمختبر عبر localhost/SSH فقط**، وليس لواجهة مكشوفة على الإنترنت. قبل الإنتاج سنستخدم تسجيل دخول بجلسات آمنة وHTTPS وصلاحيات مفصلة.
6. في هذا النموذج تستخدم خدمة SQL حساب قاعدة بيانات واحدا بصلاحيات واسعة. يجب فصل صلاحيات التطبيق والمصادقة وإعداد نسخ احتياطية قبل الإنتاج.
7. خطة نشر نهائية وتحجيم المخزون والاختبارات لم تكتمل بعد.

## مفاهيم مهمة

- قيمة MikroTik `256k/1024k` تعني **رفع 256Kbps وتنزيل 1024Kbps**.
- لا تنفذ أي تعديلات على رواتر التشغيل الحالية. استخدم MikroTik اختبار معزولا.
- لا تفتح UDP 1812/1813 للعامة، بل استخدم VPN وربط CIDR محصور بالراوترات.
- عند تغيير `RADIUS_CLIENT_CIDR` بعد إعداد VPN أعد تشغيل خدمة radius، وتحكم في الجدار الناري بشكل مستقل.
- تشغيل النظام مستقلا عن الإنترنت يفترض أن يكون الراوتر والخادم متصلين على شبكة محلية متاحة.

- اختبر التكامل في المختبر: `bash scripts/lab-account-smoke.sh` بعد `bash scripts/setup.sh && docker compose up -d --build`.
- ترفع تغييرات المرحلة الثانية إلى PR مستقل، ولا تُدمج في `main` حتى اجتياز جميع الاختبارات.

## تحديث صورة PostgreSQL 16.16 للمختبر (بوابة أمان المرحلة 01)
- البناء الجديد يستخدم Alpine 3.24 بصورتها المثبتة بالبصمة، مع تصحيح libxml2، واستبدال gosu بأداة su-exec، ومزود ICU en-US. يعتمد على اختبارات الاستعادة السابقة، وليس ترقية ملفات قاعدة البيانات مباشرة.
- تحذير: لا يمكن تشغيل مجلد بيانات Debian القديم مباشرة على Alpine. حارس البدء يرفض مجلد البيانات القديم أو غير المعتمد قبل تشغيل entrypoint. لا تحذف volume ولا تستخدم down -v ولا تنشئ علامة الاعتماد يدويا. قبل أي نقل لبيانات موجودة، استخدم إصدار المصدر القديم للنسخ الاحتياطي المنطقي المشفر، ثم اختبر الاستعادة إلى cluster جديد منفصل وراجع ترتيب النصوص والبيانات والصلاحيات. لا يتم تغيير بيانات الإنتاج آليا.
- بناء الصورة محليا: docker compose up -d --build. فحوص CI تفحص معرفات الصور التي تشغل الخدمات فعليا. لا يزال اعتماد الإصدار مشروطا بنجاح فحص FreeRADIUS وبقية بوابات الأمان.

- عند استعادة نسخة بعد توقف قاعدة المصدر، ابن صورة الاستعادة محليا أولا بواسطة `docker compose build db` (دون تشغيل الخدمة أو ربط بيانات المصدر)، ثم استخدم سكربت الاستعادة المعزول. لا يلزم أن تكون قاعدة المصدر قيد التشغيل.

## مسار تثبيت محلي اختياري بـ C# (مختبر فقط)

هذا المسار مستقل عن التثبيت الأساسي، ويتطلب Ubuntu/Debian وDocker محليا على المقبس الافتراضي وصور DB وAPI وFreeRADIUS مبنية ومختبرة مسبقا من نفس الإصدار. لا يحتاج Python أو .NET SDK على المضيف لتشغيل المهيئ الجديد، ولا ينزل صورا. يتطلب Docker Engine وCompose وflock وopenssl وsha256sum وcurl مثبتة مسبقا. يفحص توافق صور Linux المحلية مع معمارية محرك Docker (amd64 أو arm64)، ويرفض الصور المفقودة أو تكرار معرف صورة بين الأدوار قبل إنشاء مجلد التثبيت. يشغل Compose مع --pull never و--no-build صراحة. لا يعني قبول المعمارية أن arm64 اختبرت فعليا؛ لا تزال حزمة نقل الصور واختبار جهاز غير متصل مرحلة مستقلة. صورة FreeRADIUS الأساسية لا تزال تحتوي على Python للرجوع، بينما نجحت الصورة المخففة في اختبارات التشغيل والفحص الأمني دون Python. لا تستخدمه لترقية قاعدة حقيقية أو ربط MikroTik.

```bash
# استبدل المتغيرات بمعرفات sha256 الكاملة للصور المحلية الموثوقة؛ RADIUS_IMAGE_ID للصورة المخففة.
RADIUS_LOCAL_INSTALL_ACK=local-lab-only bash scripts/install-csharp-local-lab.sh \
  "$HOME/radius-local-lab" "$DB_IMAGE_ID" "$API_IMAGE_ID" "$RADIUS_IMAGE_ID"
```

اختر مجلدا جديدا لا يوجد مسبقا (مسار مطلق دون مسافات). يسجل الأمر رابط الإدارة المحلي العشوائي في api-url، واسم المشروع في project-id، وبيانات المختبر في stack.env المحمي 0600 داخل مجلد 0700. لا تطبع ملف الأسرار في تقارير الدعم. يوفر المختبر HTTP Basic على loopback فقط؛ لا يمثل نشر HTTPS للإنتاج. لا تعاود أمر التثبيت على المجلد نفسه؛ يتوقف عند وجوده. عند الفشل تبقى الموارد والملفات للفحص، ولا توجد إزالة آلية أو رجوع تلقائي إلى Python. استخدم المسار الأساسي القائم مستقلا عند الحاجة. لا يعتبر الاختبار تثبيتا مثبتا على Mini PC فعلي.

### استعمال الصورة المخففة في المثبت المحلي

أصبحت الصورة المخففة هي الخيار الافتراضي للمثبت المحلي الجديد: مرر معرفها الكامل بعد بنائها واختبارها. هذا النمط يرفض الصورة التي تحتوي على Python أو ملفات الترحيلات القديمة قبل إنشاء موارد جديدة. لاختيار الصورة القديمة صراحة أضف `RADIUS_LOCAL_RUNTIME=compatible` قبل أمر التثبيت السابق. لا يتم تغيير التثبيت الأساسي أو تحويل قاعدة بيانات قائمة تلقائيا.

يحفظ المثبت نسخ Compose المستخدمة في مجلد compose داخل مجلد التثبيت، ويستعمل SQL من bundle، فلا تحتاج عمليات تشغيل الخدمات اللاحقة إلى مسارات ملفات المستودع. تبقى المسارات المطلقة للمجلد الخاص والصور المحلية لازمة؛ لا تنقل المجلد أو تغير tags أو ملفات الأسرار يدويا. بيانات الدخول لا تطبع في السجل. في التثبيت الجديد يحفظ المثبت أمر الإدارة المستقل manage.sh، ويقارن بصمات ملفات التثبيت وهويات الحاويات الأصلية قبل تنفيذ أي إجراء. لا يعيد إنشاء الحاويات المفقودة ولا يزيل البيانات تلقائيا. فحص البصمات يحمي من التغييرات العرضية وليس توقيعا مستقلا. يتطلب المثبت الجديد flock من util-linux (Ubuntu/Debian)، ويمنع تداخل أوامر الإدارة لنفس التثبيت بقفل حصري على المجلد، دون ملف قفل متروك. تستهدف أوامر التشغيل والإيقاف معرفات الحاويات الكاملة التي تم التحقق منها. لا يحمي القفل من تدخل مسؤول Docker مباشرة خارج manage.sh.

```bash
state="$HOME/radius-local-lab"
bash "$state/manage.sh" status
bash "$state/manage.sh" stop
bash "$state/manage.sh" start
```

إذا فقدت حاوية أو تغير ملف من ملفات التثبيت، توقف وراجع سبب المشكلة واستخدم مسار الاستعادة المعزول بدلا من إعادة التثبيت على البيانات القائمة. المثبتات الأقدم لا تحتوي manage.sh تلقائيا ولا تعدلها هذه المرحلة. ما زال هذا مختبرا محليا لا يمثل اعتماد الإنتاج.

### حزمة نقل مختبر محلي (مرشح اختباري)

على جهاز التحضير الذي يحتوي صور الإصدار الثلاث الموثوقة (DB/API/FreeRADIUS المخففة):

```bash
RADIUS_LOCAL_INSTALL_ACK=local-lab-only bash scripts/offline-csharp-local-lab.sh export \
  "$HOME/radius-transfer" "$DB_IMAGE_ID" "$API_IMAGE_ID" "$RADIUS_IMAGE_ID"
```

انقل المجلد الناتج إلى الجهاز الجديد، واحتفظ ببصمة SHA256SUMS التي يطبعها المصدر عبر قناة مستقلة موثوقة. قبل تشغيل أي سكربت من الحزمة تحقق من البصمة ومن الملفات (داخل المجلد المنقول، وباستخدام البصمة الموثوقة لا قيمة مقدمة من الحزمة وحدها):

```bash
cd /absolute/path/radius-transfer
printf '%s  SHA256SUMS\n' "$TRUSTED_MANIFEST_SHA256" | sha256sum -c - &&
sha256sum --check --strict SHA256SUMS &&
RADIUS_LOCAL_INSTALL_ACK=local-lab-only bash scripts/offline-csharp-local-lab.sh install \
  "$HOME/radius-local-lab" "$TRUSTED_MANIFEST_SHA256"
```

الحزمة لا تضم بيانات مستخدمين أو ملفات إعدادات خاصة من التثبيت؛ تضم صورا موثوقة جاهزة، والترحيلات العشرة وملفات التشغيل المحددة فقط. لا تستخدم صورا مجهولة المصدر أو Docker خاصا بالإنتاج. Docker وCompose وأدوات المضيف مطلوبة مسبقا. التحقق من البصمات ليس توقيعا رقميا؛ استيراد الصور الموثوقة إلى المحرك المحلي إجراء صريح. لا ترقية تلقائية ولا اعتماد لجهاز معزول فعليا أو ARM64.

اختبار CI الإلزامي للحزمة يشغل محرك Docker منفصلا بمخزن صور وبيانات جديدين، داخل namespace خاص للشبكة دون مسار افتراضي خارجي، ويتحقق من خلو المحرك قبل استيراد الحزمة ومن تشغيل الخدمات وإعادة تشغيلها. يستعمل الاختبار sudo على مضيف GitHub Actions مؤقت فقط، وليس جزءا من حزمة التثبيت. لا يمثل اختبار Mini PC مادي أو اعتماد إنتاج.

تصحيح توافق Docker 29: تسجل حزمة النقل نمط تخزين الصور (containerd أو classic) ضمن SHA-256 وترفض الجهاز ذي النمط المختلف قبل الاستيراد؛ لأن معرفات الصور قد تختلف رغم تطابق المحتوى. يجب إعادة تصدير الحزم التجريبية الأقدم التي لا تتضمن image-store.txt. لا يعدل المثبت إعدادات Docker تلقائيا. اختبار العزل يستخدم containerd خاصا بمقبس ومخزني بيانات وحالة منفصلين عن المضيف.
